## Как устроены материалы

- В каждой папке видео `README.md` содержит описание и метаданные; `transcript.cleaned.md` — полный очищенный текст с таймкодами.
- У некоторых старых материалов есть `sections/`, `sections.yaml` и тематические блоки внутри README. Это исторический формат; отсутствие этих файлов само по себе не ошибка.
- Согласно [`AGENTS.md`](../AGENTS.md), **подготовленный к обсуждению** ролик содержит разделы `## Кратко` и `## Навигация` непосредственно в `transcript.cleaned.md`. Старые блоки в README не подменяют эту проверку.
- Ссылки, уникальные YouTube Video ID, статусы, описания и теги учитываются в [общем INDEX](../INDEX.md), а не дублируются в этом навигаторе.
