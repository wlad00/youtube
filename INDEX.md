# INDEX

Общий поисковый каталог роликов в репозитории.

Новый ролик попадает сюда сразу при регистрации ссылки — до скачивания субтитров и до создания структуры. На этом этапе фиксируются доступные метаданные источника.

Для `mvp/` отсутствие `subtitles.<язык>.srt` означает «субтитры не скачаны», наличие такого файла — «скачаны». Статус структуры берётся из `structure_status` в `README.md` ролика. После `structure_status: ready` поисковые метаданные в этой строке обновляются из YAML front matter того же `README.md`.

Для авторских коллекций наличие `<base>.<язык>.srt` означает скачанные субтитры, а наличие `<base>.structure.md` — созданную структуру.
