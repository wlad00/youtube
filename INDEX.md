# INDEX

Каталог всех роликов репозитория. Одна строка — один ролик.

**Первичный поиск информации о роликах начинай с этого файла.** Список ниже позволяет быстро найти нужный раздел или ролик и сузить поиск по тегам. В `README.md` конкретного ролика переходи только когда нужна подробная структура и содержание.

Ролик попадает сюда сразу при команде «прими ролик» — до субтитров и до структуры. Источник истины — файлы ролика: есть `subtitles.<язык>.srt` → субтитры «да»; `structure_status: ready` в `README.md` → структура «да». Теги берутся из front matter `README.md` после создания структуры.
