# MVP

Коллекция YouTube-роликов по теме быстрого заработка.

Каждому ролику — отдельная папка с читаемым именем:

```text
mvp/<ГГГГ-ММ-ДД-slug-названия>/
  README.md
  subtitles.<язык-оригинала>.srt   # только после явной команды скачать субтитры
```

Если точный день публикации неизвестен, используется `ГГГГ-ММ-slug-названия`.

## Регистрация

При простом добавлении ролика:

- получить доступные базовые метаданные страницы видео;
- создать папку и `README.md`;
- сразу добавить запись в корневой `INDEX.md`;
- отметить в индексе: субтитры — не скачаны, структура — не создана;
- не искать и не скачивать субтитры без отдельной явной команды.

Пустой `.pending.srt` не создаётся. Отсутствие `subtitles.<язык>.srt` уже означает, что субтитры не скачаны.

## README ролика

`README.md` — единый файл ролика: сначала он хранит источник и базовые метаданные, а после обработки субтитров туда же добавляются структура, резюме, теги и другие поисковые данные. Отдельный `structure.md` для `mvp` не нужен.

При регистрации в YAML front matter ставится `structure_status: pending`. После создания структуры — `structure_status: ready`.

## Субтитры

Скачивается только оригинальная языковая дорожка и только по отдельной явной просьбе пользователя.

Имя файла отражает фактический оригинальный язык:

- `subtitles.ru.srt` — только если оригинал русский;
- `subtitles.uk.srt` — если оригинал украинский;
- `subtitles.en.srt` — если оригинал английский;
- и т. д.

Машинные переводы не скачиваются.
