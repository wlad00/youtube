# MVP

Быстрые заготовки для YouTube-роликов по теме быстрого заработка.

Каждая ссылка хранится в отдельной папке по Video ID:

```
mvp/<video-id>/
  README.md
  subtitles.pending.srt
```

`README.md` фиксирует исходную ссылку, Video ID и текущий статус. `subtitles.pending.srt` — пустая заготовка: субтитры не скачиваются, пока об этом нет отдельной просьбы.
