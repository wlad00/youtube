# MVP

Заготовки для YouTube-роликов по теме быстрого заработка.

Каждому ролику — отдельная папка с читаемым именем по тому же принципу, что и остальные файлы репозитория:

```text
mvp/<ГГГГ-ММ-ДД-slug-названия>/
  README.md
  <ГГГГ-ММ-ДД-slug-названия>.pending.srt
  <ГГГГ-ММ-ДД-slug-названия>.<язык>.srt
  <ГГГГ-ММ-ДД-slug-названия>.structure.md
```

Если точный день публикации неизвестен, используется `ГГГГ-ММ-slug-названия`.

Video ID не используется как название папки. Он хранится в `README.md` и `INDEX.md` вместе с названием, ссылкой, датой публикации и другими доступными базовыми метаданными источника.

## Регистрация ролика

Когда ролик просто добавляют в коллекцию:

- получить доступные метаданные страницы видео;
- создать папку, `README.md` и пустой `.pending.srt`;
- сразу добавить запись в корневой `INDEX.md`;
- отметить: субтитры — не скачаны, структура — не создана;
- не искать и не скачивать субтитры без отдельной явной команды пользователя;
- не создавать содержательные теги до появления `*.structure.md`.

`.pending.srt` — только маркер того, что субтитры ещё не скачаны.
