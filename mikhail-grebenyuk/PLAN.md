`Субтитры = да` — есть `transcript.cleaned.md`. `Подготовлен = да` — есть `SUMMARY.md`, а при длине очищенного текста больше 40 000 знаков ещё и файлы `sections/`. Наличие старой шапки или старых sections без SUMMARY подготовкой не считается. Длина существующих транскриптов посчитана как число знаков UTF-8, без содержательного чтения.

## Порядок обработки одной записи

1. Проверить точный Video ID в INDEX и README. Если папка или очищенный транскрипт уже есть, использовать их; новый экземпляр не создавать. Для нового ID выполнить обычный приём ролика по AGENTS.md.
2. **Скачать оригинальные субтитры**, если `transcript.cleaned.md` отсутствует. Машинный перевод не использовать; отсутствие подходящей оригинальной дорожки отметить у записи.
3. **Очистить субтитры**: убрать повторы rolling captions, сохранить таймкоды, создать цельный `transcript.cleaned.md`; после успешной очистки удалить сырой SRT.
4. **Подготовить ролик** по целому очищенному тексту. До 40 000 знаков включительно — SUMMARY.md с навигацией; больше 40 000 — SUMMARY.md, смысловые границы sections.yaml и нарезка скриптом в sections/. Это правило подготовки, а не фильтр очереди.
5. Обновить метаданные и INDEX по результату, затем статусы записи и счётчики этого плана. После чтения транскрипта при необходимости уточнить основную тему.

Существующие 11 очищенных транскриптов оставшейся очереди повторно скачивать не требуется. При сужении очереди новые субтитры, SUMMARY, скрипты и папки отдельных роликов не создавались.
